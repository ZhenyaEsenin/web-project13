# API-контракт проекта "Учёт затрат"

## Назначение
Настоящий документ описывает интерфейс взаимодействия между клиентской частью и серверным API для работы с основными сущностями проекта: транзакции, категории, проекты.

## Базовый адрес API
`http://localhost:3001`

---

## Ресурс: Транзакции

### 1. Получение списка транзакций

**Метод:** `GET`
**Адрес:** `/transactions`
**Назначение:** получение коллекции расходов для отображения в списке и на главной странице.

**Успешный ответ:**
- **Код:** `200 OK`
- **Тело:** Массив объектов `TransactionResponseDto`

---

### 2. Получение транзакции по идентификатору

**Метод:** `GET`
**Адрес:** `/transactions/{id}`
**Назначение:** получение полной карточки расхода.

**Параметры пути:**
- `id` — целочисленный идентификатор транзакции

**Успешный ответ:**
- **Код:** `200 OK`
- **Тело:** Объект `TransactionResponseDto`

**Возможные ошибки:**
- `404 Not Found` — транзакция не существует

---

### 3. Создание новой транзакции

**Метод:** `POST`
**Адрес:** `/transactions`
**Назначение:** создание новой записи о расходе.

**Заголовки:**
- `Content-Type: application/json`
- `Accept: application/json`

**Тело запроса:** Объект `TransactionCreateDto`

**Успешный ответ:**
- **Код:** `201 Created`
- **Тело:** Объект `TransactionResponseDto`

**Возможные ошибки:**
- `400 Bad Request` — некорректный формат тела запроса
- `422 Unprocessable Entity` — логически некорректные данные

---

### 4. Обновление транзакции

**Метод:** `PUT`
**Адрес:** `/transactions/{id}`
**Назначение:** полная замена данных транзакции.

**Параметры пути:**
- `id` — идентификатор транзакции

**Тело запроса:** Объект `TransactionUpdateDto`

**Успешный ответ:**
- **Код:** `200 OK`
- **Тело:** Объект `TransactionResponseDto`

**Возможные ошибки:**
- `404 Not Found`
- `422 Unprocessable Entity`

---

### 5. Удаление транзакции

**Метод:** `DELETE`
**Адрес:** `/transactions/{id}`
**Назначение:** удаление записи о расходе.

**Параметры пути:**
- `id` — идентификатор транзакции

**Успешный ответ:**
- **Код:** `200 OK` или `204 No Content`

**Возможные ошибки:**
- `404 Not Found`

---

**Метод:** `GET`
**Адрес:** `/projects`

## Набор запросов для коллекции Postman
1 `GET /items` — получение списка объектов.
2 `GET /items/{id}` — получение карточки объекта.
3 `POST /items` — создание новой записи.
4 `PUT /items/{id}` — обновление существующего объекта.
5 `DELETE /items/{id}` — удаление объекта.
