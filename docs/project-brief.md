# Сквозной проект: Учёт затрат проекта

## Тема
Система учёта расходов по проектам с возможностью категоризации и построения аналитики.

## Основные сущности

### Транзакция (расход)
- Название (краткое описание траты)
- Сумма (в рублях)
- Дата операции
- Категория (связь с сущностью "Категория")
- Проект (связь с сущностью "Проект")
- Комментарий (опционально)

### Категория
- Название
- Цвет/метка
- Бюджет

### Проект
- Название проекта
- Описание
- Бюджет проекта
- Даты начала/окончания

## Функциональные требования

### Основные операции
- Добавление расхода (сумма, категория, дата, проект)
- Редактирование расхода
- Просмотр списка расходов
- Фильтрация по периодам (день, неделя, месяц, произвольный период)
- Фильтрация по категориям и проектам

### Аналитика
- Отчёт по категориям (суммы расходов в разрезе категорий)
- Отчёт по проектам
- Динамика расходов по дням/неделям

## Экраны (минимально)

1. Главная/Дашборд — сводная информация, графики, последние расходы
2. Список транзакций — таблица всех расходов с фильтрами
3. Карточка транзакции — детальный просмотр расхода
4. Форма транзакции — создание/редактирование расхода
5. Аналитика по категориям — отчёт с суммированием по категориям
6. Управление категориями (опционально)
7. Вход в систему (заглушка для будущей авторизации)
